🛠️ دليل إعداد الجسر المحلي (Local Bridge Setup)

لتفعيل أدوات التحكم في نظام التشغيل (OS Control)، اتبع الخطوات التالية لإعداد خادم Node.js المحلي:

  1. قم بتثبيت Node.js على جهازك.
  2. أنشئ مجلداً باسم vsa-bridge وضع فيه ملفاً باسم server.js.
  3. الصق الكود التالي داخل الملف:
const express = require('express'); const fs = require('fs'); const cors = require('cors'); const { exec } = require('child_process'); const app = express(); app.use(cors()); app.use(express.json()); // سرد الملفات المحلية app.get('/list', (req, res) => { const dirPath = req.query.path || '.'; fs.readdir(dirPath, { withFileTypes: true }, (err, files) => { if (err) return res.status(500).json({ error: err.message }); res.json(files.map(f => ({ name: f.name, type: f.isDirectory() ? 'dir' : 'file' }))); }); }); // تنفيذ أوامر النظام app.post('/cmd', (req, res) => { exec(req.body.command, (error, stdout, stderr) => { res.json({ output: stdout, error: stderr || error }); }); }); app.listen(3000, () => console.log('🚀 Local Bridge Active on port 3000'));

تحذير: هذا الجسر يمنح النموذج صلاحية كاملة على جهازك. استخدمه في بيئة تطوير آمنة فقط.

⚙️ منطق دعم الأدوات في ai_engine_core.js

إليك كيف يفرق ملف البرمجة الأساسي بين أدوات السحاب (Cloud) وأدوات الويندوز (Local):

1. أدوات بيئة GitHub (السحابية):

تستخدم دالة callBridge() التي ترسل الطلب إلى SUPABASE_BRIDGE_URL. الجسر السحابي هو من يمتلك مفاتيح التشفير للوصول لـ GitHub.

2. أدوات بيئة Windows (المحلية):

تستخدم دالة callLocalBridge() التي تحاول الاتصال بـ localhost:3000. إذا كان الخادم المحلي يعمل، يتم تنفيذ الأمر مباشرة على جهازك.

// مثال من كود معالجة الأدوات if (name === "os_command") { // توجيه ذكي للجسر المحلي toolResult = await callLocalBridge('cmd', { command: args.command }); } else if (name === "read_file") { // توجيه للجسر السحابي (GitHub) toolResult = await getGithubFileContent(args.path); }
