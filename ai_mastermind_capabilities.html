🌉 بنية الجسر السيادي (Bridge Architecture)

يعمل الجسر كبوابة أمنية (Secure Gateway) تربط بين الواجهة الأمامية والخدمات الحساسة:

⚡ Supabase Edge Functions (Deno)

تعمل في بيئة Deno Runtime على حافة الشبكة. ميزتها هي التعامل الآمن مع Secrets (مثل GEMINI_API_KEY) دون تسريبها للعميل.

// مثال لمنطق الجسر في Supabase serve(async (req) => { const { action, payload } = await req.json(); if (action === 'chat') { const apiKey = Deno.env.get("GEMINI_API_KEY"); // الاتصال بـ Google API وإرجاع النتيجة } });

☁️ Cloudflare Workers (V8)

تشبه وظائف Supabase ولكنها تعمل في بيئة V8 Isolates. تستخدم لتوجيه الطلبات (Routing) وتخزين البيانات المؤقتة عبر KV Storage.

🚀 تكامل المحركات والـ APIs

كيف يتم تعريف ووضع الأدوات في النظام:

1. تعريف الأداة في العقل المدبر (AI Engine):

يتم إرسال مصفوفة function_declarations داخل ملف ai_engine_core.js لتخبر النموذج بوجود أداة يمكنه طلبها.

2. تعريف المحرك في الجسر (Bridge API):

يتم وضع مفاتيح API (مثل Google Search أو Tavily) في إعدادات البيئة (Env Vars). يقوم الجسر بالتبديل بين المحركات (Fallback Logic) في حال وصول أحدها لسقف الاستخدام.
