# 🧠 دليل أنظمة وكلاء الذكاء الاصطناعي (AI Agent Systems Reference)
**الإصدار:** 1.0 - توثيق هندسي للمشروع

هذا المستند يُلخص الأنواع المختلفة لأنظمة الوكلاء الذكية بناءً على علوم الحاسوب وهندسة الذكاء الاصطناعي، مرتبة من البسيطة إلى الأكثر تعقيداً.

---

### 1. وكلاء رد الفعل (Reactive Agents)
*   **الوصف:** أبسط أنواع الوكلاء. يعمل بناءً على قاعدة "إذا حدث (س) افعل (ص)".
*   **المميزات:** سرعة استجابة فائقة.
*   **العيوب:** لا يمتلك ذاكرة، لا يخطط، ولا يفهم السياق البعيد.
*   **مثال:** نظام إغلاق التداول تلقائياً عند وصول السعر لنقطة معينة.

### 2. نظام الوكلاء المتخصصين (Specialized Agent System)
*   **الوصف:** تقسيم النظام إلى وحدات، كل وحدة (محرك) خبيرة في مجال محدد (ذاكرة، منطق، تنفيذ).
*   **المميزات:** دقة عالية في المهام المحددة، سهولة الصيانة.
*   **العيوب:** يحتاج لمتحكم مركزي قوي ليربط بين المحركات.
*   **الوضع الحالي:** هو الهيكل الأساسي لمحركاتك الستة.

### 3. نظام الوكلاء الهرمي (Hierarchical Agent System)
*   **الوصف:** بنية إدارية حيث يوجد "وكيل قائد" يوزع المهام على "وكلاء عمال". القائد يرى الهدف الكبير، والعمال يرون المهام الصغيرة.
*   **المميزات:** ممتاز للمشاريع الضخمة التي تتطلب إدارة موارد معقدة.
*   **العيوب:** إذا فشل القائد، يتوقف النظام بالكامل.

### 4. نظام وكلاء الند للند (Peer-to-Peer / Collaborative)
*   **الوصف:** لا يوجد قائد. الوكلاء يتواصلون ويتفاوضون فيما بينهم مباشرة لحل المشكلة.
*   **المميزات:** نظام مرن جداً وغير مركزي (Decentralized).
*   **العيوب:** تعقيد كبير في بروتوكولات التواصل بين الوكلاء.

### 5. الوكلاء الاستباقيون (Proactive / Goal-Directed)
*   **الوصف:** وكيل لا ينتظر الأوامر. يراقب البيئة باستمرار ويعمل من تلقاء نفسه لتحقيق أهداف طويلة الأمد.
*   **المميزات:** تقليل التدخل البشري لأدنى حد.
*   **العيوب:** قد يتخذ قرارات غير متوقعة إذا لم تُضبط أهدافه بدقة.

### 6. الأنظمة الهجينة (Hybrid Agent Systems)
*   **الوصف:** دمج المنطق البرمجي الصارم (Code) مع المنطق العصبي (LLMs).
*   **المميزات:** يجمع بين دقة البرمجيات التقليدية وذكاء النماذج اللغوية.
*   **مثال:** نظامك الحالي الذي يربط محرك JavaScript مع Gemini API.

### 7. النظام الذاتي (Autonomous Agent System)
*   **الوصف:** أعلى مراحل التطور. يمتلك النظام "حلقة مغلقة" (Closed-Loop) تمكنه من:
    1. **التخطيط الذاتي:** تقسيم الهدف إلى مهام.
    2. **التنفيذ المستقل:** استخدام الأدوات.
    3. **التحقق الذاتي:** فحص النتائج وتصحيح الأخطاء تلقائياً.
*   **الوضع الحالي:** هو النظام الذي قمنا بترقية مشروعك إليه مؤخراً.

### 8. وكلاء التعلم المستمر (Learning Agents)
*   **الوصف:** وكيل يطور "كود التفكير" الخاص به بناءً على التجارب السابقة. يمتلك "محرك نقد" يقيم أداءه ويحدث سياسات العمل.
*   **المميزات:** النظام يصبح أذكى مع مرور الوقت دون تدخل برمجي جديد.

---

**ملاحظة هندسية:** الانتقال بين هذه الأنواع يتطلب بنية تحتية قوية (مثل فصل الملفات واستخدام محركات الاستمرارية) لضمان عدم ضياع "سياق المهمة".
